🚀 1. Persiapan Awal

1.1 Pastikan Docker Terinstal

Buka terminal/command prompt dan jalankan:

Terminal docker --version

Output yang diharapkan: Docker version 24.0.7, build afdd53b

📌 Catatan: Jika belum terinstal, download di https://www.docker.com/products/docker-desktop

1.2 Buat Folder Proyek

Terminal mkdir hello-docker cd hello-docker

🚀 2. Membuat File Aplikasi

2.1 File: index.html

Buat file index.html dan copy kode berikut:

HTML <!DOCTYPE html> <html lang="id"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Hello Docker</title> <link rel="stylesheet" href="style.css"> </head> <body> <div class="container"> <h1 id="greeting">Loading...</h1> <button onclick="ubahPesan()">Klik Saya!</button> <p id="info">Aplikasi berjalan di dalam Docker Container</p> </div> <script src="script.js"></script> </body> </html>

2.2 File: script.js

Buat file script.js dan copy kode berikut:

JavaScript // Fungsi untuk mengubah pesan saat tombol diklik function ubahPesan() { const greeting = document.getElementById('greeting'); const messages = [ 'Hello World dari Docker! 🐳', 'Selamat Belajar Docker!', 'Container itu keren!', 'JavaScript + Docker = ❤️', 'Halo dari dalam Container!' ]; // Pilih pesan secara acak const randomIndex = Math.floor(Math.random() * messages.length); greeting.textContent = messages[randomIndex]; // Efek animasi sederhana greeting.style.transform = 'scale(1.2)'; setTimeout(() => { greeting.style.transform = 'scale(1)'; }, 300); } // Fungsi ini berjalan otomatis saat halaman dimuat window.onload = function() { const greeting = document.getElementById('greeting'); greeting.textContent = 'Hello World! 🌍'; console.log('Aplikasi berhasil dijalankan di Docker!'); };

2.3 File: style.css

Buat file style.css dan copy kode berikut:

CSS * { margin: 0; padding: 0; box-sizing: border-box; } body { font-family: 'Arial', sans-serif; background: linear-gradient(135deg, #667eea 0%, #764ba2 100%); min-height: 100vh; display: flex; justify-content: center; align-items: center; margin: 0; } .container { background: white; border-radius: 20px; padding: 50px 60px; box-shadow: 0 20px 60px rgba(0,0,0,0.3); text-align: center; max-width: 500px; transition: transform 0.3s; } .container:hover { transform: translateY(-5px); } h1 { color: #333; font-size: 2.5em; margin-bottom: 25px; transition: all 0.3s ease; } button { background: linear-gradient(135deg, #667eea 0%, #764ba2 100%); color: white; border: none; padding: 12px 35px; font-size: 1.1em; border-radius: 50px; cursor: pointer; transition: all 0.3s ease; box-shadow: 0 5px 15px rgba(102, 126, 234, 0.4); } button:hover { transform: translateY(-2px); box-shadow: 0 8px 25px rgba(102, 126, 234, 0.6); } button:active { transform: translateY(0); } #info { margin-top: 25px; color: #888; font-size: 0.9em; border-top: 2px solid #f0f0f0; padding-top: 20px; }

🚀 3. Membuat Dockerfile

Buat file bernama Dockerfile (tanpa ekstensi) dan copy kode berikut:

Dockerfile # Pilih base image (Nginx versi alpine yang ringan) FROM nginx:alpine # Hapus file default Nginx RUN rm -rf /usr/share/nginx/html/* # Copy semua file aplikasi ke dalam container COPY index.html /usr/share/nginx/html/ COPY script.js /usr/share/nginx/html/ COPY style.css /usr/share/nginx/html/ # Expose port 80 (port default Nginx) EXPOSE 80
📌 Penjelasan:
  • FROM nginx:alpine → Menggunakan Nginx versi ringan (~20MB)
  • RUN rm -rf → Membersihkan file default Nginx
  • COPY → Menyalin file dari komputer ke container
  • EXPOSE 80 → Memberi tahu Docker akan menggunakan port 80

🚀 4. Build Image Docker

4.1 Build Image

Jalankan perintah di terminal (pastikan berada di folder hello-docker):

Terminal docker build -t hello-web .
✅ Output yang diharapkan:
[+] Building 2.3s (8/8) FINISHED
=> [1/4] FROM docker.io/library/nginx:alpine
=> [2/4] RUN rm -rf /usr/share/nginx/html/*
=> [3/4] COPY index.html /usr/share/nginx/html/
=> [4/4] COPY script.js /usr/share/nginx/html/
=> exporting to image
=> => naming to docker.io/library/hello-web

4.2 Cek Image yang Telah Dibuat

Terminal docker images

Anda akan melihat image hello-web di daftar.

🚀 5. Menjalankan Container

5.1 Jalankan Container

Terminal docker run -d -p 8080:80 --name hello-container hello-web
📌 Penjelasan:
  • docker run → Menjalankan container
  • -d → Detached mode (berjalan di background)
  • -p 8080:80 → Mapping port 8080 (host) ke 80 (container)
  • --name hello-container → Nama container
  • hello-web → Nama image

5.2 Cek Container Berjalan

Terminal docker ps

5.3 Buka di Browser

Akses: http://localhost:8080

✅ Uji Coba Aplikasi:
  • Klik tombol "Klik Saya!"
  • Pesan akan berubah-ubah setiap kali tombol diklik
  • Anda akan melihat halaman Hello World yang cantik

🚀 6. Mengatasi Masalah Update Otomatis

⚠️ MASALAH: Ketika Anda mengubah file, container tidak otomatis mendeteksi perubahan.

SOLUSI 1: Volume Mounting (Untuk Development)

6.1 Hentikan container lama:

Terminal docker stop hello-container docker rm hello-container

6.2 Jalankan dengan volume mount:

Untuk Linux/Mac:

Terminal docker run -d -p 8080:80 -v $(pwd):/usr/share/nginx/html --name hello-dev hello-web

Untuk Windows (Command Prompt):

CMD docker run -d -p 8080:80 -v %cd%:/usr/share/nginx/html --name hello-dev hello-web

Untuk Windows (PowerShell):

PowerShell docker run -d -p 8080:80 -v ${PWD}:/usr/share/nginx/html --name hello-dev hello-web
✅ Sekarang coba ubah file:
  • Edit index.html, script.js, atau style.css
  • Refresh browser di http://localhost:8080
  • Perubahan akan langsung terlihat! ✨

SOLUSI 2: Rebuild Image (Untuk Production)

Terminal # Build ulang image docker build -t hello-web . # Hentikan container lama docker stop hello-container docker rm hello-container # Jalankan container baru docker run -d -p 8080:80 --name hello-container hello-web

🚀 7. Perintah Penting Docker

7.1 Manajemen Container

Perintah Fungsi
docker ps Melihat container yang berjalan
docker ps -a Melihat semua container (termasuk yang berhenti)
docker stop hello-container Menghentikan container
docker start hello-container Menjalankan container yang sudah berhenti
docker rm hello-container Menghapus container
docker logs hello-container Melihat log container
docker logs -f hello-container Melihat log secara real-time
docker exec -it hello-container sh Masuk ke dalam container (untuk debugging)

7.2 Manajemen Image

Perintah Fungsi
docker images Melihat semua image
docker rmi hello-web Menghapus image
docker image prune Menghapus semua image yang tidak digunakan

🚀 8. Docker Compose (Opsional)

8.1 Buat File docker-compose.yml

Buat file bernama docker-compose.yml dan copy kode berikut:

YAML version: '3.8' services: web: build: . container_name: hello-dev ports: - "8080:80" volumes: - ./:/usr/share/nginx/html # Untuk development, override command agar Nginx tidak cache command: nginx -g "daemon off;"

8.2 Perintah Docker Compose

Perintah Fungsi
docker-compose up -d Menjalankan container
docker-compose logs -f Melihat log
docker-compose down Menghentikan container
docker-compose up -d --build Rebuild dan jalankan ulang
docker-compose ps Melihat status

🚀 9. Troubleshooting

Masalah 1: Port sudah digunakan

Terminal # Cek proses yang menggunakan port 8080 # Linux/Mac: sudo lsof -i :8080 # Windows: netstat -ano | findstr :8080 # Gunakan port berbeda docker run -d -p 8081:80 --name hello-container hello-web

Masalah 2: Permission denied (Linux/Mac)

Tambahkan :delegated pada volume:

Terminal docker run -d -p 8080:80 -v $(pwd):/usr/share/nginx/html:delegated --name hello-dev hello-web

Masalah 3: Perubahan tidak terlihat

  • Hard refresh browser: Ctrl+Shift+R atau Ctrl+F5
  • Bersihkan cache browser
  • Cek log container: docker logs hello-dev

Masalah 4: Container tidak bisa dihapus

Terminal # Hentikan dulu container docker stop hello-container # Baru hapus docker rm hello-container # Atau hapus paksa docker rm -f hello-container
