🎓 Materi Belajar PostgreSQL CRUD

Panduan step-by-step untuk pemula — dari nol sampai bisa

STEP 1 Pengenalan Database

Apa itu Database?

Database adalah tempat menyimpan data secara terstruktur. Bayangkan seperti lemari arsip:

  • Database = lemari
  • Tabel = laci
  • Baris (row) = satu lembar data
  • Kolom (column) = isian di lembar

Apa itu CRUD?

4 operasi dasar di database:

HurufArtiPerintah SQL
CCreate (buat)INSERT
RRead (baca)SELECT
UUpdate (ubah)UPDATE
DDelete (hapus)DELETE
💡 Info Semua aplikasi (Instagram, WhatsApp, Tokopedia) pakai 4 operasi ini di balik layar.

STEP 2 Install PostgreSQL

Windows

  1. Download dari postgresql.org/download/windows
  2. Jalankan installer → Next sampai selesai
  3. Password superuser: ketik postgres (atau apa saja, INGAT!)
  4. Port: biarkan default 5432
  5. Buka SQL Shell (psql) dari Start Menu

Linux (Ubuntu/Debian)

# Install PostgreSQL sudo apt update sudo apt install postgresql postgresql-contrib sudo -u postgres psql

Mac

brew install postgresql brew services start postgresql psql postgres

Cek Berhasil

Kalau muncul prompt seperti ini, berarti berhasil:

postgres=#
⚠️ Tips Kalau stuck, tekan Ctrl + D atau ketik \q lalu Enter untuk keluar.

STEP 5 Membuat Tabel

Tabel = tempat menyimpan data. Seperti sheet di Excel, tapi lebih terstruktur.

Bikin Tabel siswa

CREATE TABLE siswa ( id SERIAL PRIMARY KEY, nama VARCHAR(100) NOT NULL, kelas VARCHAR(20), umur INT, jurusan VARCHAR(50) );

Tipe Data Penting

TIMESTAMPTanggal + waktu'2024-01-15 10:30'

Constraint (Aturan)

STEP 6 CREATE — Menambah Data

Tambah 1 Data

INSERT INTO siswa (nama, kelas, umur, jurusan) VALUES ('Budi Santoso', 'X-IPA-1', 15, 'Teknik Informatika');

Struktur:

INSERT INTO [nama_tabel] ([kolom1], [kolom2], ...) VALUES ([nilai1], [nilai2], ...);
⚠️ Aturan
  • Teks pakai tanda kutip ' (petik satu)
  • Angka tidak pakai kutip
  • Kolom id tidak diisi (otomatis dari SERIAL)

Tambah Banyak Sekaligus

INSERT INTO siswa (nama, kelas, umur, jurusan) VALUES ('Ani Wijaya', 'X-IPA-2', 16, 'Sistem Informasi'), ('Citra Dewi', 'XI-IPA-1', 17, 'Teknik Komputer'), ('Dodi Pratama', 'X-IPA-1', 15, 'Teknik Informatika'), ('Eka Putri', 'XII-IPS-3', 18, 'Manajemen');

Cek Data Masuk

SELECT * FROM siswa;

✅ Latihan

STEP 7 READ — Membaca Data

Tampilkan Semua

SELECT * FROM siswa;

Tanda * = semua kolom.

Tampilkan Kolom Tertentu

SELECT nama, kelas FROM siswa;

Filter dengan WHERE

-- Siswa kelas X-IPA-1 saja SELECT * FROM siswa WHERE kelas = 'X-IPA-1'; -- Siswa umur lebih dari 15 SELECT * FROM siswa WHERE umur > 15; -- Kombinasi (AND) SELECT * FROM siswa WHERE kelas = 'X-IPA-1' AND umur = 15; -- Kombinasi (OR) SELECT * FROM siswa WHERE kelas = 'X-IPA-1' OR kelas = 'X-IPA-2';

Operator Perbandingan

OperatorArti
=Sama dengan
!= atau <>Tidak sama
>Lebih besar
<Lebih kecil
>=Lebih besar sama dengan
<=Lebih kecil sama dengan

Urutkan (ORDER BY)

-- Urut nama A-Z SELECT * FROM siswa ORDER BY nama ASC; -- Urut umur besar ke kecil SELECT * FROM siswa ORDER BY umur DESC;

Batasi Hasil (LIMIT)

SELECT * FROM siswa LIMIT 2;

Cari yang Mirip (LIKE)

SELECT * FROM siswa WHERE nama LIKE 'A%'; -- diawali A SELECT * FROM siswa WHERE nama LIKE '%i'; -- diakhiri i SELECT * FROM siswa WHERE nama LIKE '%wi%'; -- mengandung 'wi'

% artinya "apa saja".

Hitung Jumlah Data

SELECT COUNT(*) FROM siswa;

✅ Latihan

STEP 8 UPDATE — Mengubah Data

Struktur Dasar

UPDATE [tabel] SET [kolom] = [nilai baru] WHERE [kondisi];

Ubah 1 Kolom

UPDATE siswa SET umur = 16 WHERE nama = 'Budi Santoso';

Ubah Beberapa Kolom

UPDATE siswa SET kelas = 'XI-IPA-1', umur = 16 WHERE id = 1;
🚨 ATURAN EMAS — JANGAN LUPA WHERE!
❌ BAHAYA! Semua umur jadi 99! UPDATE siswa SET umur = 99;

Kebiasaan Aman

-- 1. Cek dulu dengan SELECT SELECT * FROM siswa WHERE nama = 'Budi Santoso'; -- 2. Baru UPDATE UPDATE siswa SET umur = 16 WHERE nama = 'Budi Santoso'; -- 3. Cek hasil SELECT * FROM siswa WHERE nama = 'Budi Santoso';

✅ Latihan

STEP 9 DELETE — Menghapus Data

Struktur Dasar

DELETE FROM [tabel] WHERE [kondisi];

Hapus 1 Data

DELETE FROM siswa WHERE id = 4;

Hapus dengan Kondisi

-- Hapus siswa umur kurang dari 15 DELETE FROM siswa WHERE umur < 15; -- Hapus siswa kelas XII DELETE FROM siswa WHERE kelas LIKE 'XII%';
🚨 ATURAN EMAS — JANGAN LUPA WHERE!
❌ BAHAYA! SEMUA DATA HILANG! DELETE FROM siswa;

Kosongkan Tabel (Tapi Tabel Tetap Ada)

TRUNCATE TABLE siswa;

Bedanya dengan DELETE:

  • DELETE → hapus baris satu-satu, bisa rollback
  • TRUNCATE → hapus semua sekaligus, lebih cepat, tidak bisa rollback

Hapus Tabel Sekalian

DROP TABLE siswa;

✅ Latihan

STEP 12 SQL Injection — Studi Kasus Login Bypass

Setelah paham CRUD, kamu wajib paham ini. Ini serangan paling klasik dan paling berbahaya di dunia web.

⚠️ Peringatan Materi ini untuk pembelajaran. Uji SQL Injection hanya di lab milik sendiri atau platform resmi (HackTheBox, TryHackMe, DVWA). Menguji website orang lain tanpa izin = pidana.

1. Skenario Awal — Aplikasi Login Rentan

Bayangkan ada aplikasi login. Di balik layar, kodenya seperti ini (❌ RENTAN):

# Kode Python rentan username = input("Username: ") password = input("Password: ") query = "SELECT * FROM user WHERE nama = '" + username + "' AND password = '" + password + "'" cursor.execute(query)
⚠️ Masalahnya String username dan password digabung langsung ke dalam query. Ini pintu masuk SQL Injection.

2. Kasus Normal — User Jujur Login

Input user:

  • Username: budi
  • Password: rahasia123

Query yang terbentuk:

SELECT * FROM user WHERE nama = 'budi' AND password = 'rahasia123'

Database cek: ada user budi DAN password rahasia123? Ya → login berhasil. ✅

3. Kasus Penyerang — Input admin'--

Input penyerang:

  • Username: admin'--
  • Password: apa_saja (bisa kosong)

Query yang terbentuk:

SELECT * FROM user WHERE nama = 'admin'--' AND password = 'apa_saja'

Lihat bagian yang ditandai merah? Itu kuncinya.

4. Kunci Serangan: -- adalah Komentar

Di SQL, -- artinya komentar. Apa pun setelahnya diabaikan oleh database.

-- Contoh komentar SELECT * FROM user WHERE nama = 'admin'-- ini diabaikan

5. Query yang Benar-Benar Dijalankan

Query asli:

SELECT * FROM user WHERE nama = 'admin'--' AND password = 'apa_saja'

Database memotong di --:

SELECT * FROM user WHERE nama = 'admin'
💀 Bagian AND password = '...' HILANG! Password tidak dicek sama sekali. Cukup user admin ada di database → login berhasil.

6. Ilustrasi Visual

Query asli yang dibuat aplikasi: ┌─────────────────────────────────────────────────────┐ │ SELECT * FROM user WHERE nama = 'admin'--' AND password │ └─────────────────────────────────────────────────────┘ ↓ Database potong di sini (--) Query yang benar-benar dijalankan: ┌──────────────────────────────────┐ │ SELECT * FROM user WHERE nama = │ │ 'admin' │ └──────────────────────────────────┘ ↓ Return baris admin ↓ Login BERHASIL 🚨

7. Variasi Payload SQL Injection

Penyerang tidak cuma pakai admin'--. Banyak variasi:

PayloadEfekDatabase
admin'--Potong sisa querySemua
admin'#Komentar ala MySQLMySQL
admin'/*Komentar blockSemua
' OR '1'='1Selalu TRUESemua
' OR 1=1--Selalu TRUE + potongSemua
budi'--Login sebagai budiSemua

8. Contoh Payload ' OR 1=1--

Input:

  • Username: ' OR 1=1--
  • Password: (kosong)

Query yang terbentuk:

SELECT * FROM user WHERE nama = '' OR 1=1--' AND password = ''

Setelah dipotong:

SELECT * FROM user WHERE nama = '' OR 1=1

1=1 selalu TRUE → semua baris dikembalikan → login sebagai user pertama (biasanya admin). 🚨

9. Simulasi di PostgreSQL (Lab)

Coba sendiri di psql:

-- 1. Bikin tabel user CREATE TABLE user_login ( id SERIAL PRIMARY KEY, nama VARCHAR(50), password VARCHAR(50) ); -- 2. Isi data INSERT INTO user_login (nama, password) VALUES ('admin', 'admin123'), ('budi', 'rahasia456'); -- 3. Query RENTAN dengan payload admin'-- SELECT * FROM user_login WHERE nama = 'admin'--' AND password = 'apapun';

Hasil:

id | nama | password ----+-------+---------- 1 | admin | admin123 -- Password TIDAK dicek! Baris admin tetap keluar! 🚨

10. Cara Mencegah — Parameterized Query

❌ Kode Rentan:

query = "SELECT * FROM user WHERE nama = '" + username + "' AND password = '" + password + "'" cursor.execute(query)

✅ Kode Aman:

query = "SELECT * FROM user WHERE nama = %s AND password = %s" cursor.execute(query, (username, password))
✅ Kenapa Aman?
  • %s adalah placeholder — database yang mengisi, bukan kita
  • Input admin'-- dianggap string biasa, bukan perintah
  • Query tidak bisa dipotong
  • Password tetap dicek

Query yang dijalankan database:

SELECT * FROM user WHERE nama = 'admin''--' AND password = 'apa_saja'

Perhatikan: ' di-escape jadi ''. Query tidak terpotong.

🔐 BONUS Keamanan untuk Siswa Cyber

Setelah paham CRUD & SQL Injection, kamu wajib tahu ini:

1. Jangan Simpan Password Plaintext

-- ❌ SALAH INSERT INTO user (nama, password) VALUES ('budi', 'rahasia123'); -- ✅ BENAR (hash pakai bcrypt/argon2) INSERT INTO user (nama, password_hash) VALUES ('budi', '$2b$12$...');

2. Least Privilege

Buat user database dengan hak terbatas:

CREATE USER app_user WITH PASSWORD 'StrongP@ss!'; GRANT SELECT, INSERT, UPDATE, DELETE ON ALL TABLES IN SCHEMA public TO app_user; -- JANGAN kasih SUPERUSER

3. Selalu Pakai WHERE di UPDATE/DELETE

Kesalahan paling sering → data massal hilang.

4. Backup Rutin

pg_dump nama_db > backup.sql

5. Jangan Tampilkan Error SQL ke User

❌ SALAH: "ERROR: syntax error at or near 'admin'--'" ✅ BENAR: "Login gagal, silakan coba lagi."

6. Log Aktivitas Login

CREATE TABLE login_log ( id SERIAL PRIMARY KEY, username VARCHAR(50), status VARCHAR(10), ip_address INET, waktu TIMESTAMP DEFAULT CURRENT_TIMESTAMP );
