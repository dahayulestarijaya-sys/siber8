STEP 1 Pengenalan

Apa yang Akan Kita Buat?

Form login sederhana dengan PHP + PostgreSQL. Ada 2 versi:

Versi File Fungsi
Rentan index.php Demo SQL Injection (sengaja salah)
Aman aman.php Demo pencegahan (parameterized query)

Alur

[Browser] → [PHP] → [PostgreSQL] ↑ ↑ ↑ Form Proses Database

Yang Akan Dipelajari

  • Cara SQL Injection terjadi
  • Payload admin'-- dan ' OR 1=1--
  • Cara mencegah dengan parameterized query
  • Perbedaan kode rentan vs aman
💡 Kenapa PHP? PHP paling praktis untuk demo — 1 file, langsung jalan, tidak butuh framework.

STEP 4 Versi Rentan (index.php)

Buat file index.php di folder ~/lab-login-php.

Kode Lengkap

<?php // ===== KONEKSI DATABASE ===== $host = 'localhost'; $port = '5432'; $dbname = 'lab_login'; $user = 'yusufyacobonaola'; // ganti sesuai user macOS kamu $password = ''; // kosong try { $pdo = new PDO("pgsql:host=$host;port=$port;dbname=$dbname", $user, $password); $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION); } catch (PDOException $e) { die("Koneksi gagal: " . $e->getMessage()); } // ===== PROSES LOGIN ===== $query = ''; $rows = []; $sukses = false; $error = ''; if ($_SERVER['REQUEST_METHOD'] === 'POST') { $username = $_POST['username']; $password = $_POST['password']; // ❌❌❌ INI YANG SALAH — GABUNG STRING LANGSUNG ❌❌❌ $query = "SELECT * FROM users WHERE username = '$username' AND password = '$password'"; try { $stmt = $pdo->query($query); $rows = $stmt->fetchAll(PDO::FETCH_ASSOC); $sukses = count($rows) > 0; } catch (PDOException $e) { $error = 'Error: ' . $e->getMessage(); } } ?> <!-- HTML form --> <form method="POST"> <input type="text" name="username" required> <input type="text" name="password" required> <button type="submit">Login</button> </form>
🚨 Bagian RENTAN
$query = "SELECT * FROM users WHERE username = '$username' AND password = '$password'";
Input user digabung langsung ke string query. Ini pintu masuk SQL Injection.

Cara Kerja

  1. User isi form → dikirim ke PHP
  2. PHP gabung input ke string query
  3. Query dikirim ke PostgreSQL
  4. PostgreSQL eksekusi query

STEP 5 Versi Aman (aman.php)

Buat file aman.php di folder yang sama.

Kode Lengkap

<?php // ===== KONEKSI DATABASE ===== $host = 'localhost'; $port = '5432'; $dbname = 'lab_login'; $user = 'yusufyacobonaola'; $password = ''; try { $pdo = new PDO("pgsql:host=$host;port=$port;dbname=$dbname", $user, $password); $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION); } catch (PDOException $e) { die("Koneksi gagal: " . $e->getMessage()); } // ===== PROSES LOGIN ===== $query = ''; $rows = []; $sukses = false; $error = ''; if ($_SERVER['REQUEST_METHOD'] === 'POST') { $username = $_POST['username']; $password = $_POST['password']; // ✅✅✅ PARAMETERIZED QUERY — AMAN ✅✅✅ $query = "SELECT * FROM users WHERE username = :username AND password = :password"; try { $stmt = $pdo->prepare($query); $stmt->execute([ ':username' => $username, ':password' => $password ]); $rows = $stmt->fetchAll(PDO::FETCH_ASSOC); $sukses = count($rows) > 0; } catch (PDOException $e) { $error = 'Error: ' . $e->getMessage(); } } ?> <!-- HTML form (sama seperti index.php) -->
✅ Bagian AMAN
  • :username dan :password = placeholder
  • PHP kirim nilai terpisah lewat execute()
  • PostgreSQL tidak bisa dipotong query-nya

STEP 7 Uji SQL Injection

Tes 1: Login Normal

FieldIsi
Usernameadmin
Passwordadmin123

Hasil: ✅ Login berhasil

Query:

SELECT * FROM users WHERE username = 'admin' AND password = 'admin123'

Tes 2: 🚨 SQL Injection — Bypass Password

FieldIsi
Usernameadmin'--
Passwordapapun

Hasil: ✅ Login BERHASIL! 🚨

Query:

SELECT * FROM users WHERE username = 'admin'--' AND password = 'apapun'
💀 Yang Terjadi
  • -- = komentar SQL
  • Bagian ' AND password = 'apapun' diabaikan
  • Query jadi: SELECT * FROM users WHERE username = 'admin'
  • Password tidak dicek

Tes 3: 🚨 SQL Injection — OR 1=1

FieldIsi
Username' OR 1=1--
Passwordapapun

Hasil: Semua user muncul di tabel

Query:

SELECT * FROM users WHERE username = '' OR 1=1--' AND password = 'apapun'

1=1 selalu TRUE → semua baris dikembalikan.

Tes 4: Versi Aman

Buka aman.php, coba lagi admin'--:

Hasil: ❌ Login GAGAL ✅

Query:

SELECT * FROM users WHERE username = :username AND password = :password -- Values: username = "admin'--", password = "apapun"

Nilai admin'-- dianggap string biasa, bukan perintah SQL.

✅ Checklist Uji Coba

STEP 8 Pencegahan

Bandingkan Kode

❌ RENTAN
$query = "SELECT * FROM users WHERE username = '$username' AND password = '$password'"; $stmt = $pdo->query($query);
✅ AMAN
$query = "SELECT * FROM users WHERE username = :username AND password = :password"; $stmt = $pdo->prepare($query); $stmt->execute([ ':username' => $username, ':password' => $password ]);

Checklist Anti SQL Injection

Contoh Hash Password di PHP

// Saat registrasi $hash = password_hash($password, PASSWORD_BCRYPT); // Saat login if (password_verify($password, $hash_dari_db)) { // Login berhasil }

Buat User Database Terbatas

CREATE USER app_user WITH PASSWORD 'StrongP@ss!'; GRANT SELECT, INSERT, UPDATE, DELETE ON ALL TABLES IN SCHEMA public TO app_user; -- JANGAN kasih SUPERUSER
