2.2 Apa Itu Onion Service?

Onion Service = website yang hanya bisa diakses via jaringan Tor, dengan alamat .onion.

Karakteristik:

  • ✅ Anonim (IP tersembunyi)
  • ✅ Alamat unik (56 karakter)
  • ✅ Tidak bisa diakses browser biasa
  • ✅ Tidak ada registrasi terpusat

2.3 Analogi Sederhana

Surface Web  = Rumah dengan alamat di peta
Deep Web     = Rumah dengan pagar & kunci
Dark Web     = Rumah di lorong bawah tanah rahasia
               (hanya yang tahu lorong bisa masuk)

🛠️ 3. Praktik: 8 Langkah (20 Menit)

1 Install Tools (3 menit)

Buka Terminal, sesuaikan perintah dengan distro Anda:

Ubuntu / Debian / Linux Mint / Pop!_OS

sudo apt update
sudo apt install tor python3 torbrowser-launcher -y

Fedora / RHEL / CentOS

sudo dnf install tor python3 torbrowser-launcher -y

Arch / Manjaro

sudo pacman -S tor python torbrowser-launcher

openSUSE

sudo zypper install tor python3 torbrowser-launcher
✅ Verifikasi: 
tor --version
# Output: Tor version 0.4.x.x

python3 --version
# Output: Python 3.x.x

2 Siapkan Folder Konten (2 menit)

# Buat folder terpisah untuk konten (PENTING!)
mkdir -p ~/onion-site
cd ~/onion-site

# Buat file index.html
cat > index.html << 'EOF'
<!DOCTYPE html>
<html>
<head>
  <title>Onion Service Pertama Saya</title>
  <style>
    body {
      font-family: system-ui, sans-serif;
      background: #0f172a;
      color: #e2e8f0;
      max-width: 600px;
      margin: 60px auto;
      padding: 20px;
      text-align: center;
    }
    h1 { color: #38bdf8; }
    .badge {
      background: #7c3aed;
      padding: 4px 12px;
      border-radius: 20px;
      font-size: 12px;
    }
  </style>
</head>
<body>
  <div class="badge">🧅 Onion Service</div>
  <h1>Halo dari Dark Web!</h1>
  <p>Ini website Tor pertama saya di Linux.</p>
</body>
</html>
EOF
⚠️ PENTING: Jangan taruh file di folder /var/lib/tor/hidden_service/ — folder itu hanya untuk kunci rahasia!

3 Konfigurasi Tor (3 menit)

Konfigurasi Tor di Linux ada di /etc/tor/torrc. Ada dua cara — pilih salah satu.

Cara A: Pakai systemctl (Direkomendasikan)

# Edit file konfigurasi Tor
sudo nano /etc/tor/torrc

Cari dan hapus tanda # di depan dua baris ini:

HiddenServiceDir /var/lib/tor/hidden_service/
HiddenServicePort 80 127.0.0.1:8080

Simpan: Ctrl + O → Enter → Ctrl + X

Cara B: Pakai File Konfigurasi Sendiri (Untuk Belajar)

# Buat file konfigurasi custom
nano ~/torrc

Isi:

SocksPort 9050
HiddenServiceDir /home/NAMA_USER/.tor/hidden_service/
HiddenServicePort 80 127.0.0.1:8080
Ganti NAMA_USER dengan username Linux Anda (cek: whoami)

Simpan: Ctrl + O → Enter → Ctrl + X

4 Jalankan Web Server (2 menit)

Terminal 1 — biarkan terbuka:

cd ~/onion-site
python3 -m http.server 8080 --bind 127.0.0.1
✅ Output: Serving HTTP on 127.0.0.1 port 8080...

5 Jalankan Tor (3 menit)

Pilih sesuai cara konfigurasi Anda:

Kalau pakai Cara A (systemctl):

sudo systemctl restart tor
sudo systemctl enable tor   # agar otomatis jalan saat boot

Kalau pakai Cara B (file sendiri):

# Terminal 2 — biarkan terbuka
tor -f ~/torrc

Tunggu hingga muncul:

Bootstrapped 100% (done)

6 Dapatkan Alamat .onion (1 menit)

Terminal 3:

Kalau pakai Cara A:

sudo cat /var/lib/tor/hidden_service/hostname

Kalau pakai Cara B:

cat ~/.tor/hidden_service/hostname

Output:

wvltwi6ebzidebcgy6y2wptlrkph3swkvybszhpywgpcys5pbq4tts2qd.onion
📝 Catat alamat ini! Ini alamat unik website Anda.

7 Akses via Tor Browser (3 menit)

Jalankan Tor Browser:

torbrowser-launcher

Atau cari Tor Browser di application menu.

Langkah:

  1. Klik Connect → tunggu "Connected"
  2. Ketik alamat .onion Anda di address bar
  3. Halaman muncul! 🎉

Cek koneksi Tor (opsional):

https://check.torproject.org

8 Uji Keamanan (3 menit)

Test 1: Akses dari browser biasa

Buka Firefox/Chrome → ketik alamat .onion

Hasil: ❌ Gagal — karena bukan jaringan Tor

Test 2: Cek file kunci tidak terekspos

Di Tor Browser, buka: http://[alamat].onion/hostname

Hasil: ✅ 404 Not Found — artinya folder konten terpisah dari kunci

Test 3: Cek dari device lain

Install Onion Browser di iPhone → connect Tor → buka alamat .onion

Hasil: ✅ Bisa diakses (selama komputer Linux menyala)

4.2 Struktur Folder yang Aman

Cara A (systemctl):

/var/lib/tor/hidden_service/    ← 🔒 HANYA kunci (owner: debian-tor)
├── hostname
├── hs_ed25519_secret_key
└── hs_ed25519_public_key

~/onion-site/                    ← 🌐 Konten publik
└── index.html

Cara B (file sendiri):

~/.tor/hidden_service/           ← 🔒 HANYA kunci
├── hostname
├── hs_ed25519_secret_key
└── hs_ed25519_public_key

~/onion-site/                    ← 🌐 Konten publik
└── index.html

4.3 Permission yang Benar

# Untuk Cara B (user biasa)
chmod 700 ~/.tor/hidden_service/

# Untuk Cara A (systemctl)
sudo chown -R debian-tor:debian-tor /var/lib/tor/hidden_service/
sudo chmod 700 /var/lib/tor/hidden_service/

4.4 Backup Kunci (WAJIB!)

# Cara A
sudo cp -r /var/lib/tor/hidden_service/ ~/backup-onion-$(date +%Y%m%d)/

# Cara B
cp -r ~/.tor/hidden_service/ ~/backup-onion-$(date +%Y%m%d)/

# Amankan backup
chmod -R 700 ~/backup-onion-*/
⚠️ Kalau kunci hilang → alamat .onion hilang selamanya!

5.2 Kuis Singkat

1. Apa perbedaan Deep Web dan Dark Web?

Deep Web = tidak terindeks tapi legal (email, bank). Dark Web = bagian Deep Web yang butuh Tor, anonim.

2. Kenapa folder konten harus terpisah dari folder kunci?

Agar file kunci (hostname, private key) tidak terekspos ke publik via web server.

3. Apa perbedaan Cara A (systemctl) dan Cara B (file sendiri)?

Cara A = Tor jalan sebagai service, otomatis start saat boot, owner debian-tor. Cara B = Tor jalan manual sebagai user biasa, cocok untuk belajar.

4. Apa yang terjadi jika komputer Linux dimatikan?

Onion Service tidak bisa diakses. Alamat .onion tetap ada, tapi server offline.

5. Kenapa permission folder hidden_service harus 700?

Agar hanya owner yang bisa baca/tulis/akses. Tor menolak jalan jika permission terlalu terbuka, karena kunci privat sangat sensitif.
