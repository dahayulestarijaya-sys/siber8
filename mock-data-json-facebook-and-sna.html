1. Apa Itu JSON?

JSON adalah format teks untuk menyimpan data. Facebook, Instagram, WhatsApp — semuanya pakai JSON.

Contoh JSON sederhana: 
{
  "nama": "Budi",
  "umur": 25,
  "aktif": true
}

Aturan Wajib:

Aturan✅ Benar❌ Salah
Kunci pakai kutip"nama"nama
String pakai kutip ganda"Budi"'Budi'
Tanpa koma terakhir[1, 2][1, 2,]
Boolean huruf keciltrueTrue

3. Apa Itu SNA?

SNA (Social Network Analysis) = cara menganalisis hubungan antar akun.

Analogi:
  • JSON = "apa isi percakapan"
  • SNA = "siapa bicara dengan siapa"

Konsep Dasar:

IstilahArtiContoh
NodeTitik / akunBudi, Siti
EdgeHubunganBudi berteman Siti
DegreeJumlah koneksiBudi punya 5 teman

4. Data SNA dalam JSON

Data SNA butuh 2 bagian: nodes (daftar akun) dan edges (daftar hubungan).

{
  "nodes": [
    { "id": "A", "name": "Budi" },
    { "id": "B", "name": "Siti" },
    { "id": "C", "name": "Andi" }
  ],
  "edges": [
    { "source": "A", "target": "B" },
    { "source": "B", "target": "C" },
    { "source": "A", "target": "C" }
  ]
}
Artinya:
  • Budi berteman Siti
  • Siti berteman Andi
  • Budi berteman Andi

5. Contoh Jaringan Sederhana

Budi (A) / \ / \ Siti (B) -- Andi (C)

Semua saling terhubung. Ini disebut triangle (segitiga).

NodeNamaDegree
ABudi2
BSiti2
CAndi2
Kesimpulan: Semua punya degree sama (2) → seimbang, tidak ada yang dominan.

6. Contoh Jaringan Bot

Bot1 --- Bot2 \ / \ / Bot3 / \ / \ Bot4 --- Bot5
{
  "nodes": [
    { "id": "B1", "name": "bot_01", "type": "bot" },
    { "id": "B2", "name": "bot_02", "type": "bot" },
    { "id": "B3", "name": "bot_03", "type": "bot" },
    { "id": "B4", "name": "bot_04", "type": "bot" },
    { "id": "B5", "name": "bot_05", "type": "bot" }
  ],
  "edges": [
    { "source": "B1", "target": "B2" },
    { "source": "B1", "target": "B3" },
    { "source": "B2", "target": "B3" },
    { "source": "B3", "target": "B4" },
    { "source": "B3", "target": "B5" },
    { "source": "B4", "target": "B5" }

🚨 Ciri jaringan bot:
  • Semua node bertipe "bot"
  • Saling terhubung (tidak ada koneksi ke user asli)
  • Pola terlalu rapi = tidak organik

7. Cari Aktor Utama

Dalam jaringan, ada node yang jadi pusat (penghubung). Kita cari dengan melihat degree (jumlah koneksi).

Bot1 Bot2 \ / \ / Admin ← penghubung! / \ / \ Bot3 Bot4
NodeKoneksiDegree
Bot1Admin1
Bot2Admin1
AdminBot1, Bot2, Bot3, Bot44 ⭐
Bot3Admin1
Bot4Admin1
Kesimpulan: Admin punya degree tertinggi = aktor utama. Kalau Admin di-takedown, jaringan bot runtuh.

8. Baca Data dengan Python

import json
import networkx as nx

# 1. Baca file JSON
with open("sna.json") as f:
    data = json.load(f)

# 2. Buat graph
G = nx.Graph()
for node in data["nodes"]:
    G.add_node(node["id"], name=node["name"])
for edge in data["edges"]:
    G.add_edge(edge["source"], edge["target"])

# 3. Cari node paling populer
print("Degree setiap node:")
for node, deg in G.degree():
    print(f"  {node}: {deg}")

# 4. Cari aktor utama
top = max(G.degree(), key=lambda x: x[1])
print(f"\nAktor utama: {top[0]} (degree: {top[1]})")
Output: 
Degree setiap node:
  B1: 1
  B2: 1
  B3: 1
  B4: 1
  ADM: 4

Aktor utama: ADM (degree: 4)
